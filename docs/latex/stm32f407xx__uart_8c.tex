De-\/initialize the UART peripheral. 

This function de-\/initializes the specified UART peripheral by disabling the UART, clearing all configuration and status registers, and returning the peripheral to its reset state using the RCC peripheral reset mechanism.

\hline
\end{DoxyParams}
\begin{DoxyNote}{Note}
This function waits for any ongoing transmission to complete before disabling the UART to avoid data corruption.

GPIO de-\/initialization is not handled by this function and must be performed separately if required.
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
Disabling or resetting the UART while a transmission or reception is in progress may result in data loss.

Initializes the UART peripheral with user-\/defined configuration. 

This function configures the UART peripheral registers based on the parameters stored in the \doxylink{struct_u_a_r_t___handle__t}{UART\+\_\+\+Handle\+\_\+t} structure. It sets up\+:
\begin{DoxyItemize}
\item UART operating mode (TX, RX, or TX/\+RX)
\item Baud rate
\item Word length
\item Parity control
\item Number of stop bits
\item Hardware flow control
\end{DoxyItemize}

The function programs the corresponding USART registers (CR1, CR2, CR3, and BRR) and enables the UART peripheral.

This function does not enable interrupts or DMA. Those features must be configured separately using dedicated APIs.

Enable or disable the UART peripheral. 

This function controls the main UART peripheral enable bit. When enabled, the UART peripheral becomes operational and can transmit and receive data. When disabled, the UART is stopped and its registers are not active.

\mbox{\texttt{in}}  & {\em EI\+\_\+\+DI} & Enable or disable control\+:
\begin{DoxyItemize}

\item DISABLE \+: Disable the UART peripheral
\end{DoxyItemize}\\
\hline
\end{DoxyParams}
\begin{DoxyNote}{Note}
The UART must be disabled before changing certain configuration parameters such as word length, parity, and stop bits.
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
Disabling the UART while a transmission is in progress may result in data loss. 
\end{DoxyWarning}
