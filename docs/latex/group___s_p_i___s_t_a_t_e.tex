\doxysubsubsection{Detailed Description}
Internal driver state values used to track ongoing SPI operations. 

These constants represent the current state of the SPI driver, and are used internally by APIs such as \doxylink{group___s_p_i___a_p_i___p_r_o_t_o_t_y_p_e_s_ga84fe922cab70472a7ae10fc726de8d10}{SPIx\+\_\+\+Send\+Data\+IT()} and \doxylink{group___s_p_i___a_p_i___p_r_o_t_o_t_y_p_e_s_ga185a067739ac2ed3d3115a03ceee35a3}{SPIx\+\_\+\+Receive\+Data\+IT()} to prevent re-\/entrant transfers.
