Resets the I2C peripheral registers to their default reset values. 

This function triggers a peripheral reset using the corresponding bit in the RCC-\/\texorpdfstring{$>$}{>}APB1\+RSTR register. Once the reset pulse is applied, the peripheral registers return to their hardware-\/defined reset state and the I2C peripheral clock is automatically disabled.

Reads the status of a specific I2C status flag. 

This function checks the current state of the I2C status registers (SR1 and SR2) and returns whether the requested flag is set.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em p\+I2C} & Pointer to the I2C peripheral register map (e.\+g., I2\+C1, I2\+C2, I2\+C3).\\
\hline
\mbox{\texttt{in}}  & {\em Flag\+Name} & Bitmask identifying the flag to check. Supply one of the I2C flag macros (masks), for example\+:
\begin{DoxyItemize}
\item I2\+C\+\_\+\+SR1\+\_\+\+TXE
\item I2\+C\+\_\+\+SR1\+\_\+\+RXNE
\item I2\+C\+\_\+\+SR2\+\_\+\+BUSY See I2\+C\+\_\+\+STATUS\+\_\+\+FLAG\+\_\+\+MACROS for available flags.
\end{DoxyItemize}\\
\hline
\end{DoxyParams}
\begin{DoxyNote}{Note}
Some flags reside in SR1 while others reside in SR2. This function inspects both registers as needed. It does not clear or modify flags.

Enables or disables the I2C peripheral. 

This function sets or clears the PE (Peripheral Enable) bit in the I2\+C\+\_\+\+CR1 register, thereby enabling or disabling the selected I2C peripheral.

\item DISABLE \+: Clear the PE bit to disable the peripheral.
\end{DoxyItemize}\\
\hline
\end{DoxyParams}
