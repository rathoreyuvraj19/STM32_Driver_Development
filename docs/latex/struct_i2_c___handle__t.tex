I2C peripheral handle structure. 

This structure binds together\+:
\begin{DoxyItemize}
\item The base address of the I2C peripheral register map.
\item The configuration parameters selected by the user.
\item (Future) runtime state variables for interrupt/\+DMA-\/based communication.
